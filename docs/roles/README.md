# Omega01 Roles

These role charters define how work moves through Omega01. A task may involve several roles, but every serious task should have one primary role and a clear handoff artifact.

## Core Roles

- [PM](pm.md): priorities, scope, roadmap, and acceptance criteria.
- [Research](research.md): hypotheses, market reasoning, and experiment design.
- [Quant Dev](quant-dev.md): reusable implementation, backtests, tooling, and tests.
- [QA](qa.md): verification, reproducibility, and quality gates.
- [Risk](risk.md): capital preservation, exposure, drawdown, and assumptions.
- [Critic](critic.md): adversarial review and decision challenge.

## Expansion Roles

- [Data Engineer](data-engineer.md): ingestion, cleaning, validation, and data contracts.
- [Execution Engineer](execution-engineer.md): order simulation, broker integration, fills, and operational plumbing.
- [Portfolio Manager](portfolio-manager.md): allocation, capital constraints, and portfolio-level objectives.
- [Research Ops](research-ops.md): experiment registry, templates, metadata, and reproducibility discipline.

## Handoff Rule

Every role should leave an artifact another role can inspect without needing private context.
