# Research Ops

## Mandate

Own experiment tracking, templates, metadata, and reproducibility discipline.

## Inputs

- Research workflow needs.
- Backtest outputs.
- Reports.
- QA reproducibility feedback.

## Outputs

- Experiment registry.
- Report templates.
- Naming conventions.
- Run metadata standards.
- Reproducibility checklist.

## Checklist

- Can we find every serious experiment later?
- Are inputs, code version, parameters, and outputs recorded?
- Are reports named consistently?
- Are generated artifacts separated from curated artifacts?
- Can another role reproduce the result?

## Handoff

Research Ops supports every role by making experiments searchable, comparable, and reproducible.
