# Portfolio Manager

## Mandate

Own allocation across strategies, capital constraints, portfolio objectives, and portfolio-level decisions.

## Inputs

- Candidate strategy reports.
- Risk memos.
- Correlation and exposure analysis.
- Capital constraints.
- PM priorities.

## Outputs

- Allocation proposal.
- Portfolio-level risk report.
- Rebalancing assumptions.
- Strategy inclusion or exclusion recommendation.

## Checklist

- Does the strategy add independent value?
- Does it reduce or increase portfolio drawdown?
- How does it interact with existing exposures?
- What capital allocation is justified?
- What happens when multiple strategies lose together?
- What is the rebalancing rule?

## Handoff

Portfolio Manager hands allocation decisions to PM and Risk. Execution Engineer receives approved deployment assumptions for paper/live sandbox.
